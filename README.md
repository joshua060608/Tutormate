# TutorMate (윈도우 앱 버전)

콘솔 버전과 같은 클래스(TutorMate, Student, Curriculum, ScheduleItem → Lesson / PrepTask)를 그대로 쓰고,
화면만 Windows 기본 API(Win32 + GDI)로 만든 버전입니다. **추가 설치나 외부 라이브러리는 필요 없습니다.**

## Visual Studio에서 실행
1. 새 프로젝트 → **빈 프로젝트 (C++)**
2. 이 폴더의 `.h`, `.cpp` 파일을 프로젝트 폴더에 복사 → 솔루션 탐색기에서 프로젝트 우클릭 → 추가 → 기존 항목 → 모두 선택
   (README.md, CMakeLists.txt는 추가하지 않아도 됩니다. 콘솔 버전의 main.cpp / ConsoleUI.cpp와 같은 프로젝트에 넣으면 안 됩니다)
3. 프로젝트 속성 → 구성: **모든 구성**
   - C/C++ → 언어 → C++ 언어 표준: **ISO C++17**
   - C/C++ → 명령줄 → 추가 옵션: **/utf-8** (필수, 빠뜨리면 빌드 시 안내 오류가 뜹니다)
4. Ctrl+F5 → 창이 뜹니다. 처음 실행하면 샘플 데이터를 불러올지 묻습니다.

콘솔 창 없이 바로 윈도우 창으로 실행되도록 `GuiMain.cpp`에 설정이 들어 있습니다.
데이터는 실행 폴더의 `tutormate_data.txt`에 자동 저장되며, 콘솔 버전과 같은 형식이라 서로 호환됩니다.

## 화면
| 메뉴 | 내용 |
|---|---|
| 대시보드 | 오늘 수업/준비 수, 오늘 일정(체크 가능), 다가오는 수업, 이번 주 준비 진행 도넛, 학생별 목표일 |
| 커리큘럼 관리 (기능 1) | 전체 커리큘럼 표(추가/수정/순서 이동/삭제) + 학생별 수업 계획(총 수업 가능 횟수, 자동 일정 생성, 회차별 커리큘럼 드롭다운) + 달력 |
| 학생 관리 | 학생 추가/수정/삭제, D-day, 진도 |
| 주간 시간표 (부가기능) | 주 단위 시간표, 빈 칸 클릭 → 수업 추가, 수업 클릭 → 선택된 일정 + 빠른 작업(보강/휴강/완료/커리큘럼 변경/삭제) |
| 수업 준비 (기능 2) | 요일별 준비 To-Do 카드(체크, 클릭해서 날짜 이동), 주간 계획 다시 생성, 준비 대상 수업 목록, 진행 현황 |
| 통계 / 설정 | 학생별 진행률, 주말 배정 여부, 시연용 기준 날짜, 샘플 데이터 |

## 파일 구성
- 모델(콘솔 버전과 동일): `Date`, `Curriculum`, `Student`, `ScheduleItem`, `Lesson`, `PrepTask`, `TutorMate`
- 화면: `MainWindow`(창, 7개 화면, 클릭 처리), `Canvas`(그리기 도우미), `FormDialog`(입력 창), `Win32Util.h`(UTF-8 ↔ UTF-16 변환)
- 시작점: `GuiMain.cpp`

화면 클래스는 데이터를 직접 바꾸지 않고 모두 `TutorMate`의 public 함수를 통해 처리합니다 (로직과 화면 분리).
